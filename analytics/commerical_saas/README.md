# ENG Case Study - Staff Data Analyst - Business Analytics

# Overview
Time: 4-6 hours | Format: Single document (Markdown, Google Doc, Notion, or PDF)
  
---

# Business Scenario
You're joining a software company as a Staff Data Analyst. During week one, Marketing and Sales pull you into a meeting:

**Marketing**: We're spending 50K/month on Google, LinkedIn, and Facebook ads, but can't tell what's working.

**Sales**: Half the leads never respond. We need to know which sources bring real opportunities. Also, we can't get cohort performance - are Q1 leads converting better than Q2? Data team: Can't match spend to leads.

**Both**: Fix this. We need something next sprint.
​

**Your task**: Investigate the data, identify problems, design the solution.

---

# Available Data
Marketing data (Fivetran, web analytics, CRM data, internal spreadsheets). See data dictionary for schema details.
Key sources:
- Facebook Ads: basicad, basicadset, basiccampaign, adhistory, accounthistory
- Google Ads: adstats, campaignstats
- CRM: leads, opportunities, customers
- Web: sessions, formsubmissions
- Internal: campaignmetadata, costallocation

​
---


# Your Deliverable
Single document covering these 7 sections:
​

1. Investigation Analysis: What did you discover exploring the data? Business questions? Problems identified? Prioritization?

2. Data Architecture: dbt project structure, key models, data flow diagram, naming conventions, materialization strategy. Handle challenges.

3. Business Logic: 
Define with clear formulas for **CAC** (calculation, costs, edge cases), **Lead Quality** (criteria, edge cases), **Attribution** (approach, trade-offs), **Cohort Analysis** (definition, measurement).

4. dbt Models: 3-4 examples (SQL, config, docs, tests): 1 staging, 1 intermediate, 1 mart.

5. Dashboard Design: Layout, visualizations, metrics, filters, access controls.

6. Stakeholder Communication: 15-min meeting outline (findings, questions, decisions, timeline).

Strategic Recommendation: Pick ONE (data quality monitoring, process improvements, tool optimization, team enablement, other).
